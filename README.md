# R.H-CHASE — The Ultimate Run

A mobile-friendly browser endless-runner game.

## Play locally
- Node.js 18+
- `npm install`
- `npm start`
- Open `http://localhost:3000`

## Controls
- Left/right arrows or A/D: change lanes
- Up arrow or Space: jump
- P: pause

## Deployment
Designed for a Render Node web service:
- Build: `npm install`
- Start: `npm start`
- Health check: `/health`

## Monetization status
Premium items are shown as coming soon. Real payments are intentionally not activated until a payment provider, merchant account, and verified checkout credentials are configured. Never place payment secrets in browser code.

## Notes
The game stores the best score locally in the player's browser. This is a single-player game; online accounts, cloud leaderboards, anti-cheat, and paid entitlements require backend services.
